# Giallo Booleano – Replica di Giallo Zafferano

Questo progetto è un esercizio pratico in HTML e CSS finalizzato alla replica della homepage di Giallo Zafferano, con l'aggiunta di funzionalità responsive.  
L'obiettivo principale è stato **rendere il sito adattabile a diverse risoluzioni**, utilizzando un approccio mobile-first e consolidando le competenze nella gestione di layout flessibili e media queries.

## Tecnologie utilizzate

- HTML5
- CSS3
- Media Queries
- Mobile-first design

## Obiettivi raggiunti

- Creazione di una struttura semantica e ordinata con HTML
- Suddivisione chiara e coerente del layout in sezioni
- Applicazione di stili CSS di base per definire disposizione, colori e spaziature
- Implementazione di media queries per garantire la responsività su dispositivi mobili e desktop
